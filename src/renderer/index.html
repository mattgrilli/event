Add classroom/room numbers and teacher names for better organization:

Quantity,Student Name,Classroom,Teacher

Column Name Variations (case-insensitive)

  • Quantity: Quantity, Qty
  • Name: Student Name, Name, Full Name
  • First: First, First Name
  • Last: Last, Last Name
  • Classroom: Classroom, Room, Class
  • Teacher: Teacher
